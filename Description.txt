This project is a tiny Flask app that turns a photo/scan of a doctor’s note into a downloadable .ics calendar: it uses OpenAI gpt-4o-mini for OCR, Hugging Face FLAN-T5 (with a robust heuristic fallback) to extract appointments, medications, and reminders into a strict JSON schema, then builds calendar events with sensible defaults and alarms in the America/New_York timezone; to run it, install dependencies (flask, transformers, torch, ics, dateparser, python-dateutil, pytz, openai), set OPENAI_API_KEY, start with python app.py, open http://localhost:4444, upload a PNG/JPG/WEBP/TIFF/BMP (≤12 MB), review the OCR + extracted JSON, and download the .ics to import into Google/Apple/Outlook Calendar.
